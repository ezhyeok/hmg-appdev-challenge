# 말 해석 평가 (발화 묶음, 2026-11-13)

마이크로 한 말과 질문 카드에 한 대답을 규칙 해석기(`IntentParser`)가 얼마나 맞게 읽는지 잰 결과.
LLM을 마이크 말에 먼저 쓸지 정하기 전의 기준선이다.

## 방법

- **묶음**: `rest-engine/coach/src/test/resources/voice-corpus/`
  - `mic.tsv` 327개: 마이크 버튼, 카드 없음.
  - `card.tsv` 162개: "옥산휴게소가 정체 전 마지막 화장실이에요. 들를까요?"에 대한 대답.
- **작성**: 해석기 코드와 표(`IntentParserTest`)를 보지 않은 별도 작성자가 `docs/design/coach-layer/voice.md`만 보고 썼다.
  - 실제 차 안에서 할 법한 말로, 반말·존댓말, 군말, 섞인 문장, 부정, 되묻기, 언급, 끝난 일을 넣었다.
  - 약 25%는 STT 손상이다: 띄어쓰기, 끝 글자 잘림, '들를→들을'·'휴게소→휴개소'·'화장실→화장시'처럼 잘못 들음.
- **해석 경로**: 앱과 같은 길로 해석한다. 마이크는 `parseSpoken`, 카드 대답은 `replyTo`다.
- **분할**: dev와 test로 반씩 나눈다.
  - dev: 틀린 것을 규칙으로 고치는 데 쓴다.
  - test: 재기만 한다. 고칠 때 보지 않으므로 처음 듣는 말에 대한 일반화를 잰다.
- **위험한 오답**: 다음 둘은 0개여야 통과한다.
  - 수락이 아닌 대답을 '응'으로 읽음: 원치 않는 경유지가 내비에 들어간다.
  - 급해가 아닌 마이크 말을 급해로 읽음: 급해 모드가 뜬다.
- **실행**: `./gradlew -p rest-engine :coach:test --tests '*VoiceCorpusEvalTest'`
  - 보고서는 `rest-engine/coach/build/reports/voice-corpus-{mic,card}.md`에 남는다(종류·정답별 정확도, dev의 틀린 말).

## 결과

| | 처음 | dev를 고친 뒤 |
|---|---:|---:|
| 마이크 dev (164) | 88.4% | 100% |
| 마이크 test (163) | 90.2% | **90.8%** |
| 카드 dev (81) | 87.7% | 100% |
| 카드 test (81) | 90.1% | **91.4%** |
| 위험한 오답 | 카드 3개 | **0** |

처음 나온 위험한 오답 셋:
- "정체 다 빠지고 나서 쉬자": 나중이라는 말인데 수락으로 읽었다.
- "가자 가자": 계속 가자는 뜻일 수 있다.
- "들러야 하나…": 혼잣말로 묻는 말이다.

고친 규칙:
- **카드 대답**
  - '빠지고/풀리고 나서'는 나중이다.
  - '가자'만 되풀이한 말은 모름이다.
  - '하나·될까·을까'로 끝나는 말은 묻는 말이다.
  - '지나가면서 들러'는 수락이다.
  - '거기로 가', '옥산으로 가자'(조사가 붙은 정차 이름), '화장실 보내고 가자', '갔다가 출발하자'는 수락이다.
  - '들르고 싶지 않아'는 거절이다.
  - '들을게'는 STT가 '들를게'를 잘못 들은 것이다.
- **마이크**
  - '방광 터질 것 같아'는 급해다.
  - '화장실 보내야/찾네'는 화장실 요청이다.
  - '할매'는 할머니다.
  - '기저귀 가방', '기저귀 갈아줬어', '안 먹여도 돼', '밥 먹었잖아'는 요청이 아니다.
  - '땡긴다', '아침도 못 먹고'는 배고프다는 말이다.
  - '졸다가', '꾸벅'은 졸린다는 말이다.
  - '다리 좀 펴고'는 쉬자는 말이다.
  - 다른 사람이 '지치셨대'면 쉬자는 말이다.
  - '주유소 말고 휴게소 들르자'는 '말고' 뒤의 요청을 읽는다.
  - '휴개소', '화장시', '일어나셨어'를 알아듣는다.

이 시험은 지금 값을 하한으로 둔다(dev 100%, test 마이크 90%·카드 91%, 위험한 오답 0). 규칙을 바꾸다가 내려가면 실패한다.

## LLM

- 같은 묶음으로 LLM 해석기(`PleosLlmInterpreter`)도 잴 수 있다. 시험의 분류 함수만 바꿔 끼우면 된다.
- 지금 에뮬레이터에서는 Pleos LLM 온디바이스 모드가 응답하지 않는다(2026-11-11, 40초).
- 서버 모드는 Playground 등록(Client ID)이 필요해서 아직 잴 수 없다.
- 응답하는 환경이 생기면 마이크 묶음의 test 정확도와 지연을 이 규칙 기준선과 비교해, 마이크 말에 LLM을 먼저 쓸지 정한다.
  - 카드 대답은 지연과 안전 때문에 규칙만 쓴다.
